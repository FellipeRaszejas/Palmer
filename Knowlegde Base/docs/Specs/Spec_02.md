# Spec 02 – Visualização de descrição institucional e biografia

**User Story**: Como admin, quero exibir a descrição institucional detalhada e a biografia (história, missão, diferenciais) de cada faculdade, para que os usuários tenham informações completas.

**Critérios de Aceitação**
- Página da faculdade mostra campo "Descrição Institucional".
- Área de biografia com título, texto livre e formatação básica.
- Dados são editáveis no painel de administração.
