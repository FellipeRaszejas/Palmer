# Spec 01 – Cadastro de faculdades (individual e importação)

**User Story**: Como admin, quero cadastrar faculdades individualmente ou por importação em lote, para manter o catálogo atualizado.

**Critérios de Aceitação**
- Formulário de cadastro com todos os campos obrigatórios.
- Upload de CSV/Excel para importação em lote.
- Validação de dados (CNPJ, e‑mail, etc.).
- Mensagem de sucesso ou lista de erros ao final da importação.
