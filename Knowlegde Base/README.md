# Palmer Platform Knowledge Base

Este repositório contém a documentação inicial da **Base de Conhecimento (KB)** da plataforma Palmer. Ele serve como ponto de partida para entender a arquitetura, requisitos funcionais e não‑funcionais, e demais informações relevantes para desenvolvimento, manutenção e onboarding.

## Estrutura de pastas

```
Knowlegde Base/
├─ README.md                 # Este documento
├─ docs/
│   ├─ functional_requirements.md   # Requisitos funcionais organizados por módulo
│   ├─ non_functional_requirements.md   # Requisitos não funcionais (performance, segurança, etc.)
│   ├─ architecture.md          # Visão geral da arquitetura e componentes principais
│   └─ faq.md                   # Perguntas frequentes
└─ assets/                     # Imagens, diagramas (a serem adicionados)
```

## Como usar

- **Leitura**: Comece pelo `docs/functional_requirements.md` para entender o que o sistema deve fazer.
- **Arquitetura**: Consulte `docs/architecture.md` para visão de alto nível dos componentes e fluxos.
- **NFR**: `docs/non_functional_requirements.md` detalha requisitos de desempenho, segurança e escalabilidade.
- **FAQ**: Perguntas comuns e respostas rápidas em `docs/faq.md`.

> **Nota**: Esta KB está em sua primeira versão. Você pode personalizar, expandir ou reorganizar os arquivos conforme necessário.
